# 每日每周时段功率与用电量可视化网站

这是一个可直接部署到 GitHub Pages 的中文静态网站，展示阿里 Cluster Trace GPU v2026 的 185 天、24 时段功率与用电量结果。

页面固定使用实际 GPU 型号功率估算的**中位 TDP**和 **PUE=1.56**，支持：

- 按天查看 185 天中的任意一天；
- 按周查看 27 个连续周；
- 查看全周期 24 个时段平均功率和累计用电量；
- 切换 GPU 侧、服务器非 GPU、IT 侧和数据中心侧；
- 切换功率、用电量指标；
- 下载每日、每周和 GPU 型号功率结果 CSV。

网页将数据打包在 `data.js` 中，并随站点内置 `plotly.min.js`，部署后不依赖本机 Python 服务或外部 CDN。
